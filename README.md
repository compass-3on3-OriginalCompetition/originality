# #コンパス 3on3大会 順位管理サイト

`index.html` 1ファイルで動く、大会の結果入力・順位計算サイトです。

- グループ戦：総当たり表（WIN/LOSE・勝ち数・ポータルキー）と成績表、順位を自動計算
  - 順位：取得ポータルキー合計 → 勝率（引き分け含む試合数で割る）→ 当該チーム同士の対戦結果 → 引き分けの数が多いチーム → 順位決定戦／運営抽選
  - 2試合終了時点でポータルキー差6以上のコールド勝ち（3試合目を5-0扱い）を自動判定
  - 不戦敗は0-5として記録
- 決勝トーナメント：A1 vs B2 / B1 vs A2、3位決定戦、決勝（BO3・引き分けは再試合）
- チーム設定：12チームまで、抽選でグループ分け

claude.ai のアーティファクトとして開くと共有データベースに保存されます。
ブラウザで直接開いた場合は、その端末（localStorage）に保存されます。

## スクショの読み取り・デッキ確認

`reader.js` は、#コンパスのリプレイ画面のスクショから、6人の名前・ヒーロー・カード・ポータルキーを読み取ります。
（[compass-system](https://takuayu0103-creator.github.io/compass-system/) の読み取り処理を、作者の許可を得て移植したものです。画像は端末の中だけで処理します。）

- チーム設定 → 「メンバーと提出デッキ」で、提出された「カード強化 / デッキ編集」画面のスクショをデッキごとに読み込みます
  - 画面全体のスクショなら、左上のユーザーネームとデッキの4枚を登録。4枚だけを切り抜いた画像なら、デッキだけを登録
  - チーム内のカード重複（シェアカード以外）を、カードの絵で比べて自動でチェックします
- 対戦表 → 対戦を開く → 「スクショで読み取り・確認」で、リプレイ画面の名前からメンバーを判別してポータルキーを記入し、使ったカードを提出デッキと絵で比べて、並び順に関係なく一致・不一致を判定します
